# Experiment 7: Generate Synthetic Images Using GAN

This experiment implements a Generative Adversarial Network (GAN) for generating synthetic handwritten digit images using the MNIST dataset. The dataset was loaded using TensorFlow/Keras and preprocessed by normalizing pixel values to the range [-1, 1] and reshaping the images into the required format. A Generator network was developed using Dense, Batch Normalization, LeakyReLU, and Transposed Convolutional layers to generate images from random noise. A Discriminator network was implemented using Convolutional, LeakyReLU, Dropout, Flatten, and Dense layers to distinguish between real and synthetic images. The Generator and Discriminator were trained adversarially using Binary Cross-Entropy loss and the Adam optimizer. The training process recorded Generator and Discriminator losses, and synthetic images were generated at different training epochs to observe the improvement in image quality. Finally, the generated images were compared with real MNIST images, visualized using Matplotlib, and saved for further analysis. This experiment helped in understanding GAN architecture, adversarial training, synthetic image generation, and the challenges involved in generating realistic and diverse images.
